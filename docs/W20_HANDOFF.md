## 二、今天的三轮第三方审查（R11 / R12 / R13）

### R11 → W17（3 high / 8 medium / 4 low，已全修）

**最重的一条**：W17 原来报「实测放大是理论的 7.6 倍」。
审查官证明这是**口径伪影**：对线性模型

```
|EOL 误差| ≡ 穿越点容量误差 / |b|
```

是恒等式，所以在穿越点上「实测 vs 理论」必然得 1（实测 1.0008 / 1.0084）。
初版把 h 取成 h=1（紧贴切分点、GP 还在插值），才把比值抬到 4–11 倍。

**修法**：改成三个可证伪的量——
1. 恒等式（写成断言，误差 1e-12）；
2. 容量误差从 h=1 走到穿越点涨 **4.14 / 10.92 倍**；
3. 整段 RMSE 口径 ÷ 理论 = **0.58–1.23（同量级）**
→ 结论变成 **`寿命误差 ≈ 容量误差 ÷ 斜率`**（0.01 Ah ≈ 1.4–3.3 循环），这是能用的换算。

其余：删掉无出处的 `>=3` 阈值（D26）；md 第二张表的「电池」列被 `.where` 掩码抹成「—」（D25 第五条重犯）；W17-M1 变异 ÷10 后仍有 1.97/2.90，声称的断言零覆盖。

### R12 → W19 初版（4 high / 7 medium / 6 low，已全修＝整份重写）

**最重的一条**：把 W15 的**定义层 d**（τ 挪 ±0.05 时答案平移多少）当成时间裕度减掉。
d 不是 EOL 误差；同一份 md 在 S3 说「它不是模型误差」，在 S1 又说「必须牺牲的寿命」。
而且 d 与「τ 抬到 1.45 后的真实提前量」只在 B0005 上碰巧相等（B0006 −2.5、B0018 +3.0、B0007 −11）。

**修法**：`替换时刻 = EOL(τ_hi=1.45) − (模型层 m + 数据层 s)`，
并把提前量拆成「**阈值平移**（不能省）+ **不确定性裕度**（可买小）」两列。

其余：观测长度原来用「网格最后一点 + 10」= 160，真实 168（少算 8 个循环）；S1×S2 对 B0006 不可执行（t\*=100 晚于替换时刻）；STATE 里 t\* 写成三套数。

## 八、这一天的教训（写给下次的自己）

1. **「结论比数字更容易错」**：今天两个 high（R11-H1、R12-H3）都不是算错，而是**把算对的数讲错了**。
   R11-H1 是拿一个恒等式当发现；R12-H3 是把「定义」当「误差」。
2. **凡是我自己定的阈值，都要能说出处**：R11 抓到的 `>=3`、R12 抓到的 `95% 档`，
   都属于「先有结论再挑阈值」。D26 不是形式主义。
3. **验收判据要能在删掉东西之后重放**：W20 的价值就在这——之前所有「重跑一致」都是在旧产物上覆盖，
   只有把 `outputs/` 删掉才算真的重建。
4. **清单不能放进被删的目录**：`MANIFEST.sha256` 放仓库根而不是 `outputs/`，
   否则「清空重建」这个实验自己做不了自己。
