## 二、报告是怎么造的（下次改它只需要看这里）

```powershell
cd "C:\Users\Tony Huang\SHU\大二\python\battery-health-and-lifespan-prediction"
$env:PYTHONIOENCODING="utf-8"; $env:MPLCONFIGDIR="outputs/_tmp/mplconfig"
python scripts/build_report.py     # 生成 docx
python scripts/check_report.py     # 自检：结构 + 图表引用 + 8 条数字可追
```

三条设计约束（**改报告时必须遵守**）：

1. **不手写数字**。散文里的关键数字要么来自 `outputs/`，要么在 `check_report.py` 里登记一条
   「正文 + 产物双向出现」的断言。现在有 8 条。
2. **表格从产物解析**，不重抄。`md_table(路径, 小节名)` 直接读 `outputs/tables/*.md`。
   要改表，改产物（`src/*.py`），不要改这个脚本。
3. **图是产物**，只换题注不换图。

结构：封面沿用课程模板 `../项目报告模版.docx`（学院/专业/学号/姓名/课程/评分栏），
正文用模板的 `Heading 1` / `Heading 2` / `Body Text` 样式。
目录是 **Word 域**（`TOC \o "1-3"`），打开后 `Ctrl+A → F9`（或右键「更新域」）生成。
