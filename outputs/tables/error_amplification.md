## 一、先说清一个恒等式（初版在这里栽过）

对一条直线，寿命误差与穿越点容量误差的关系是**恒等式**：

```
|EOL 误差| ≡ 穿越点容量误差 / |b|
```

两边都换成相对量再相除，容量误差会抵消：

```
放大_实测(h*) ≡ 额定容量 / (|b| · EOL) = 放大_理论
```

所以在**穿越点**上比「实测 vs 理论」什么也证明不了——它必然等于 1。本节实测：2.6315–4.7643（理论 2.6315–4.7643），差在 1e-12 以内。

**初版把 h 取成 h=1，得到的「实测是理论的 7.6 倍」是口径伪影**：h=1 紧贴切分点、GP 还在插值，误差极小；那个比值只是「穿越点误差 ÷ 近场误差」，不区分「噪声放大」和「形式偏差」——两者在穿越点都会给出同样的数。

## 四、结论

**结论一（结论②）**：同一个模型的容量误差，从第 1 个前向步走到真实穿越点，放大了 **4.1–10.9 倍**。这是「越往外推越不准」的直接度量，不依赖任何理论比值。

**结论二（结论③）**：用整段测试 RMSE 当分母，实测放大是理论放大的 **0.58–1.23 倍**——同量级。也就是说，**寿命误差基本可以由「容量误差 ÷ 斜率」解释，没有额外的机制**。

**结论三**：这条恒等式给了运维一个能用的换算：

```
寿命误差（循环）≈ 容量误差（Ah） / |b|
```

`b` 从训练数据估，`|b| ≈ 0.003–0.007 Ah/循环` ⇒ **容量差 0.01 Ah ≈ 寿命差 1.4–3.3 循环**。这比「放大 20 倍」这种说法更经得起用。

## 六、这张表不能怎么读

1. **不能在穿越点上比实测与理论**：那是恒等式（第一节）。
2. **不能用单个 h 的放大下结论**：单点误差随 h 剧烈摆动（h=1 到 h=10 之间可以差一个数量级），主结论用②与③。
3. **不能说「实测远大于理论说明形式偏差」**：见第一节，初版就是这么错的。
4. **不能把增长倍数当常数**：它由曲线形状决定，本数据只有 4 块（其中 B0018 精确命中，不进 `2` 块的统计）。
