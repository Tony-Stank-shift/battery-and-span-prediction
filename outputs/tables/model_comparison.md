## 一、口径

- **任务**：任务 A（个体内轨迹外推）。切分点 **M = 80**，时序划分，逐个体拟合。
- **电池**：4 块（B0005、B0006、B0007、B0018）。
- **四个模型**：M1 线性 / M2 双指数 / M3 随机森林（**设计好的反例**）/ M4 趋势+GPR。
- **三条读表纪律**（见 D23 / D25）：
  ① 只对**同分母**的量做比较——测试段 RMSE/MAE 可以，R² 的跨电池平均不行；
  ② **训练段指标不参与排名**（M3 记住样本、M4 平滑残差，两者都偏低）；
  ③ **EOL 有三态**——有值 / 真值删失 / 模型给不出，混在一起算就是造假。

## 五、这张表不能怎么读

1. **不能按平均 R² 排名**：R² 的分母是各自电池的测试段方差，跨电池平均没有意义（D23 实测：按 R² 与按 RMSE 排序会翻）。本表因此**只列不平均**。
2. **不能因为 M3 差就删掉它**：它的作用是反例——证明「树模型不能外推」；没有它，这个结论就只是断言。
3. **不能说「M4 比 M1 准」**：两者在远场的点预测完全相同，M4 的价值是区间（W11 已证）。表里 RMSE 的微小差别来自近场那一点局部修正。
4. **不能把这张表当跨个体（任务 B）的结论**：任务 B 的样本个体只有 3 个，LOBOCV 里零基准就打赢了所有特征模型（见 `task_b_lobocv.md`）。
