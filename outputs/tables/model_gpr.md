## 三、最重要的结论：**平稳核的 GPR 不会外推，它只会在数据外面「躺平」**

残差 GP 学到的长度尺度是 **3.62–23.00 个循环**，而观测长度是 80、外推距离是 52–88 个循环。比值最大的一块（B0007）也只有 **0.26**——也就是说 GP 的相关尺度只是外推距离的一个零头。

**但「躺平」不是立刻发生的**，这里必须精确：

- **近场**：刚离开数据时 GP 还在做局部平滑修正，最大 **0.0386 Ah**（这是它在测试段唯一真正做的事）；
- **远场**：离开数据 18–115 个循环（= 5 倍长度尺度）之后，GP 的后验均值降到 **9e-08 Ah** 量级 → **点预测就是趋势线**；
- **带宽**：数据之外 GP 单独的标准差是**常数** 0.0220–0.0345 Ah（随距离的变化最大 3.7e-13）→ **它不会随着外推变宽**。

这三条都由 `structure_checks()` 断言钉住。所以 M4 能不能讲清楚，关键不在 GP，而在**趋势项**：

- 这不是缺陷，是平稳过程的本性：RBF 核的协方差随距离指数衰减，远处必然回到先验（均值 0、方差 = 振幅）。
- 想让 GP 自己外推趋势，得换非平稳核（比如线性核叠加）或把趋势做进均值函数——本项目**故意不这么做**，因为那样「趋势不确定性」就被埋进超参里，报告里再也说不清「这条带子为什么这么宽」。
- 一个实现上的坑（第一版踩过）：把噪声交给 `WhiteKernel` 自由学，它会把噪声学成 3.6e-9、于是 GP **逐点插值** 80 个残差（训练 RMSE 4.8e-10、训练 R²=1.000）。那是过拟合，且会让对比表出现「M4 训练段完美」的假象。现在噪声下限固定为 OLS 残差方差，训练 RMSE 回到 0.0100–0.0204 Ah，可比。

这也是 M4 与 M1 的关系：M4 的点预测在远场就是 M1，**它多出来的东西主要是区间**。所以 W13 的对比表里，M4 不该在精度上大赢，它该在「能给出分布」上赢——这正是本项目的主线。

## 七、这张表不能怎么读

1. **不能把 M4 当成「比 M1 更准」**：数据之外它的点预测就是 M1。如果报告里说「GPR 提升了精度」，那是假的。
2. **不能把 95% 区间当成「真值有 95% 概率落在里面」**：它只覆盖了两层不确定性，第五节的覆盖情况已经说明它会漏。
3. **不能解释长度尺度**：ℓ≈1–4 个循环意味着「残差在这尺度上相关」，这是 80 个点的噪声结构，不是电化学时间常数。
4. **B0007 没有 EOL 误差**：它删失，没有真值。它的后验中位数是 158、90% 区间 139–179，只能看方向，不能算误差。
