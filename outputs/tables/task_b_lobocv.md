## 一、口径：任务 B 与任务 A 是两个问题

- **任务 A**（W9–W11 的 M1–M4）：给一块电池自己的前 M 个循环，外推它自己的后段。**逐个体拟合，没有「留一个体」这回事**。
- **任务 B**（本文件）：只看前 K 个循环的**特征**，预测**这块电池的寿命**。样本单位是**个体**，所以这里才用 LOBOCV（留一电池交叉验证）。
- `cycle` 在任务 B 里**不是**特征（会泄露），10 个特征全部来自 1..K 的窗口内信息。

- 观测窗口 **K = 50**（`features.K_MAIN`）；这张表每个数都依赖它。
- 有寿命标签的个体：**n = 3**；删失（无标签）的：B0007。
- 折数 = 3，**每折训练样本 = 2**。

零基准（用另外 2 个个体的寿命均值去猜被留出的那个）平均绝对误差 **14.7** 循环；最好的单特征模型（max_regen_to_K）是 **26.4**，全部 10 个特征都更差。

这不是「特征没用」——**这是 n 太小时任何交叉验证都无法回答的问题**（本数据 n = 3）。每折只有 2 个训练点，一个 2 参数的线性模型刚好用 2 个点解出 2 个参数，训练误差**恒等于 0**（`linear_2pt` 里有断言：这是恒等式，不是拟合得好）。于是「模型在训练集上完美」在这里没有任何信息量，剩下全是外推运气。

## 三、最坏的那一折：2 个点 + 跨度极小的 x = 失控

最坏一行：用 cap_first 预测 **B0006**，预测 3463 循环、真值 109，误差 **+3354** 循环。

- 训练集两个点的 x 只差 **0.0015**（这 2 个点的寿命却差 28 循环）；
- 斜率的放大系数是 **1/0.0015 ≈ 667**，于是斜率被放大到 **18666.7 循环/单位特征**（该特征三折的平均斜率是 6214.6）；
- 被留出的那个个体到最近训练点的距离是 **0.1788**，乘上被放大的斜率，直线一外推就飞了。

**这不是「近共线」**——这里只有一个自变量，谈不上共线。准确说法是：**斜率是唯一确定的（可辨识），但它的方差被 1/Δx 放大**，属于「唯一解但极不稳」。W9 的 M2 是另一种病：那条脊上有无穷多组参数给出同样的拟合（多解）。两者都让寿命数字不可信，但机制不同，报告里不能混成一句「本质一样」。

## 四、指标框架：这一轮新增了什么

| 组件 | 作用 | 谁在守门 |
|---|---|---|
| `lobocv_folds` | 留一个体的折生成 | 只挡 n<3；折的正确性由 `self_test_framework` 守 |
| `linear_2pt` | 两点线性拟合，**显式断言训练残差恒为 0** | 函数内断言（写反斜率会炸） |
| `lobocv_null` | 零基准（训练均值）——任何模型必须先赢它 | `self_test_framework` 查预测值 |
| `coverage` / `mpiw` | PICP 覆盖率与平均区间宽度（W17 用） | `self_test_framework` 查全覆盖/半覆盖/边界报错 |
| `to_common_schema` | 模型表合并成统一列序 | **缺列报错；多模型表不许被压成一个标签** |

## 五、结论：任务 B 在这份数据上只能描述

1. **不给排名**：n=3、每折训练 2 个样本，任何排序都是噪声。报告里引用「哪个特征最好」时，必须同时给 n。
2. **不给 p 值当结论**：n 这么小的时候相关系数的区间几乎覆盖 [−1, 1]，W8 已经记过这件事（10 个特征的 p 全部 > 0.20）。
3. **可以说的是方向**：特征与寿命的**符号**在 W8 里做过描述性记录，那只能当假设，等更多电池数据才能验证。
4. **任务 A 的结论不受影响**：M1–M4 是逐个体拟合，不依赖跨个体的样本量。

## 六、这张表不能怎么读

1. **不能把「零基准最好」读成「机器学习没用」**：它读成的是「本数据只有 3 个有标签的个体，不够做跨个体学习」。
2. **不能拿训练误差证明模型好**：两点拟合的训练误差恒为 0（第三节）。
3. **不能把 LOBOCV 的误差当置信区间**：3 个数的均值没有方差可言，任何 `mean ± std` 在这里都不成立。
